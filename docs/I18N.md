# 界面语言（i18n）

简体中文 / English / 日本語。决定与理由见 `docs/DECISIONS.md` 的 **D110**；这份文件只讲规矩怎么用。

## 代码在哪

| 文件 | 作用 |
| --- | --- |
| `web/src/i18n/index.ts` | `tr()`、语言检测、`<html lang>`、Intl 时间/数字、`errText()` |
| `web/src/i18n/en.ts` / `ja.ts` | 词典（键 = 中文原文） |
| `web/i18n-check.mjs` | 门禁：漏翻 / 键不齐 / 空串 |
| `.scratch/i18n/codemod.mjs` | 一次性：把中文字面量包成 `tr()`（已用完，留档） |
| `.scratch/i18n/merge.mjs` | 一次性：把翻译批次合进 `en.ts` / `ja.ts` |

## 写一条新文案

```ts
import { tr } from "./i18n/index.ts";

el("div", "sheet-title", tr("外观与语言"));                       // 静态
say(tr("已保存 · {p1}", { p1: fmtTime() }));                      // 带占位符
tr("{p1} 个会话 |count", { p1: n });                              // `|ctx` 只用于消歧，不展示
```

- 键就是**你要显示的中文**；中文界面下 `tr()` 原样返回，不查词典。
- 占位符写 `{p1}` `{p2}`，别写 `${}`。
- 一句话被拆成几段拼在 DOM 里时（`"打开 "` + 链接），键里必须带首尾空格，译文也保留。
- 时间 / 数字别手写：`fmtTime()` `fmtDate()` `fmtNum()` `fmtRelative()`。
- 改了 `web/src` 里的文案之后跑 `node web/i18n-check.mjs`，它会告诉你缺哪两条译文。

**不要**把中文留给「逻辑判断」用：`if (btn.textContent === "已复制")` 这种两边都得是 `tr("已复制")`，否则切换语言后还原逻辑就断了。

**不要**翻这些东西：模型会读到的工具说明（`bridge/ext/approval-gate.ts` 的 label / description / promptSnippet）、`docs/` 下的决策与计划、门禁的拒绝理由、`console.*` 与 `Error` 消息、CSS 类名、`localStorage` 键。

如果这类「不翻但确实要写在 `web/src` 里」的中文串必须当字面量（典型是给模型拼的指令，例：`web/src/jira-shared.ts` 的 `handoffPrompt`），把它夹在 `// i18n-ignore-start <理由>` 与 `// i18n-ignore-end` 之间：门禁既不报漏翻，也不把它当键。区间只该包住那几个字面量，别拿它挡整个文件（界面文案还得继续受管）。

## 加一门语言

1. `web/src/i18n/index.ts`：`Lang` 加一项、`LANGS` 加一行（顺序 = 面板里 chip 的顺序）、`LOCALES`、`DICTS`。
2. `web/src/i18n/xx.ts`：`export const xx: Dict = { … }`。
3. `web/src/i18n-check.mjs`：把 `xx` 加进比对。
4. `docs/DECISIONS.md` D110 的「要做什么」补一句；本文件术语表补一列。
5. `web/src/styles.css`：如果这门语言需要自己的字体栈（`html:lang(xx) { --sans: … }`）。

## 已知限制

- **繁体不做**：`zh-TW` / `zh-HK` 落简体中文。要做得加 `zh-Hant` 词典与 `LANGS` 一项。
- **不打包字体**：日文用系统字体栈，Windows 上是 Yu Gothic / Meiryo，macOS 上是 Hiragino —— 两边字形不同，属预期。
- **拼接句的语序**：把一句话拆成多个 DOM 节点的位置（`"打开 "` + 链接 + `" 输入："`）只能各语言共用同一顺序。
- **后端错误**：认不出的 `code` 会显示 bridge 给的中文兜底句子（日志里有一条 `[i18n] missing` 可查）。
