# 原型：模型弹层（5 个方案，`?variant=A…E`）

这份目录是 D345 那次「产物弹窗 → 设置控制台样式」的同一路子，用来回答：

> 输入框下沿那颗模型 chip 点开的**模型弹层**，按设置控制台（`.st-console`）的视觉语言重做之后长什么样？

**别进 main。** 定了之后把赢家折进 `web/src/app.ts`（见 issue），这份目录留在这个分支上当原始材料。

## 跑

```bash
node proto/model-sheet/build.mjs          # src.html + 主题 token + 本机模型目录 → model-dialog.html
open model-dialog.html                     # 或 ?variant=B / C / D / E
node proto/model-sheet/shots.mjs           # 五个方案各截一张图（自查用，需要 playwright）
```

底部黑色胶囊切方案，`←` `→` 循环、`1`–`5` 直达、`esc` 关弹窗（再点 chip 重开）。

## 五个方案

| | 结构 | 落点 | 提交方式 |
|---|---|---|---|
| **A** 控制台式双栏 | 左栏来源导航 + 右栏行列表 + 顶部「搜索 + 思考档位分段」 | 居中 `900×680` | 草稿 + 确认 |
| **B** 居中卡片栈 | 当前模型一张大卡 + 最近使用一排 chip + 分组行（设置页「行」语言） | 居中 `560` | 草稿 + 确认 |
| **C** 底部抽屉改造 | 位置不变（贴底），顶部来源页签 + 模型卡网格 | 贴底 `78%` | 草稿 + 确认 |
| **D** 贴 chip 即时面板 | 无标题栏、搜索优先、扁平列表 | 贴 chip 上弹 `420` | 点一下立即生效 |
| **E** A + 即时生效 | A 的外壳，底栏换成「已切到 X · 思考 max」+ 撤销胶囊 | 居中 `900×680` | 点一下立即生效 + 一步撤销 |

**用户选了 E**（A 的外壳 + 点一下立即生效 + 撤销条），会话信息盒摆进左栏底部当折叠区。

## 数据与样式都是真的

- 样式 token 由 `build.mjs` 从 `web/src/theme-tokens.css` 原样注入，四套主题变量都在，`data-theme` 一改就跟着变。
- 模型目录从 `~/.pi/agent/models.json` 读（46 个模型 / 3 个来源），只留名字、id、来源、上下文窗口 —— **apiKey 不进产物**。长名字 `Hy4（x0.29）｜hy4std`、`Xiaomi MiMo-V2.6-Pro（x0.13）` 就是拿来压省略号的。
- 假的只有外壳那层：顶栏、两条消息、composer、`.hint-tools` 里那颗 chip（按下态用来对照锚点）。

## 注意

- `model-dialog.html` 是 **build 产物**，要改就改 `src.html`，别改它。
- `shot-*.png` 是四个（加 E 共五个）方案的自查截图，`1280×860`，深色主题。
