# 提醒角标 · 五个方向（一次性原型）

**这份原型要回答的问题：** ★ 行右端那个「有人在等你」的指示器，还能长成什么样？

原话是「铃铛太丑了」。这句话值得当真：★ 行左边全是**文字胶囊**（pin-chip），顶栏也是文字按钮，突然冒出一枚彩色 emoji 铃铛 + 黄药丸，它在这套排版里是异类 —— 不是颜色没调好，是语言不对。

上一片样张（`../reminders-ui/`）定的是**清单与位置**；这一片只挑**那颗东西本身**。

## 怎么跑

双击 `index.html`。底部浮条 `‹ ›`（或 `←` `→`）换变体，`?variant=A|B|C|D|E` 直接开某一片，`换成 0 件` 看没有事情在等时各自怎么收场，`深色` 看 Mac 深色那套 token。

截图：`shot-A.png` … `shot-E.png`、`shot-F.png` … `shot-I.png`，加 `shot-D-zero.png`。重拍 `node proto/reminders-bell/shots.mjs`。

## 五个方向

| | 形态 | 赌的是 | 代价 |
| --- | --- | --- | --- |
| **A** | **文字胶囊**「等你 2」，无图标，与 pin-chip 同一种圆角细边 | 这一排已经是文字了，再放一个 emoji 就是异类 | 占宽 ≈ 76px；而且长得像 pin-chip，容易被当成可点的会话 |
| **B** | **线描铃铛**（SVG，`currentColor`）+ 数字，无底色、无黄色 | 换个图标就够，继续用「铃铛」这个全世界都认识的隐喻 | 仍是一枚图标，与这一排的文字不齐 |
| **C** | **方章数字**：1px 细边方块里一个 `2`，没有图标 | 你要的是数字，不是铃铛；它像计数器，不像提醒 | 第一眼没人知道那是什么（只有 hover title） |
| **D** | **不新增控件**：数字画在**当前会话那颗胶囊的尾巴**上 | 你在等的是会话，不是「通知」 | ★ 行空着时无处可挂；数字看起来像这个小会话自己的未读 |
| **E** | **一个点 + 小字**：6px 圆点 +「2 件在等」，颜色只到 `--faint` | 这条指示器不该抢任何注意力 | 太安静 —— 而这正是当初要做它的理由（盯中间时看不见） |

## Mac idiom（F–I）：用户说「又有 mac 风格」

这套界面的排版本来就是 Mac 的：工具条是单色 SF 线描图标，数量是**图标右上角一枚小徽标**（macOS 的 Dock / 邮箱 / 日历都这样），而不是旁边一枚黄药丸。所以按 macOS 的语言又出四片：

| | 形态 | 赌的是 | 代价 |
| --- | --- | --- | --- |
| **F** | **图标 + 右上角红徽标**（`position:absolute`，几乎不占额外宽度） | 一套排版里只该有一种提醒语言；macOS 用户一眼就懂 | 徽标压在图标上，9px 的数字在小字号会糊 |
| **G** | **只留徽标**，没有图标 | 比 F 再少一层：★ 行右端就一枚红圆数字 | 「提醒」还是「未读」全靠位置与上下文 |
| **H** | **工具条裸文字**「2 件在等」，无边框无底色，hover 才浮灰块 | 文字比图标更不像装饰 | 与 pin-chip 一样占宽，只是少了描边 |
| **I** | **图标升蓝**（`--accent`），**不显示数字** | 知道有人在等就够了，几件点开看 | 一件与五件长得一样；堆了三条也看不出来 |

## 0 件时怎么收场（原型里也拍出来了）

| A | B | C | D | E | F / G / H / I |
| --- | --- | --- | --- | --- | --- |
| 整颗消失 | 留一枚灰铃铛，无数字 | 整颗消失 | 尾巴消失（不留空圈） | 留一个灰点，无数字 | 整颗消失（已定） |

「有事才出现」还是「一直在、只是变灰」是个真实的取舍：前者干净，但位置会跳；后者稳定，但这排本来就挤。

## 结论

方向已指到 Mac idiom（F–I 那四片）。还没定的是其中哪一片 —— 也可以组合（比如「F 的徽标 + D 的位置」、「B 的图标 + G 的纯数字」）。落地时按 `web/src` 的规矩重写：`tr()` 三语、`#app` 里不许裸 `vh`/`vw`、图标走 `currentColor` 而不是 emoji。
