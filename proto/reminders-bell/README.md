# 提醒角标 · 五个方向（一次性原型）

**这份原型要回答的问题：** ★ 行右端那个「有人在等你」的指示器，还能长成什么样？

原话是「铃铛太丑了」。这句话值得当真：★ 行左边全是**文字胶囊**（pin-chip），顶栏也是文字按钮，突然冒出一枚彩色 emoji 铃铛 + 黄药丸，它在这套排版里是异类 —— 不是颜色没调好，是语言不对。

上一片样张（`../reminders-ui/`）定的是**清单与位置**；这一片只挑**那颗东西本身**。

## 怎么跑

双击 `index.html`。底部浮条 `‹ ›`（或 `←` `→`）换变体，`?variant=A|B|C|D|E` 直接开某一片，`换成 0 件` 看没有事情在等时各自怎么收场，`深色` 看 Mac 深色那套 token。

截图：`shot-A.png` … `shot-E.png` + `shot-D-zero.png`。重拍 `node proto/reminders-bell/shots.mjs`。

## 五个方向

| | 形态 | 赌的是 | 代价 |
| --- | --- | --- | --- |
| **A** | **文字胶囊**「等你 2」，无图标，与 pin-chip 同一种圆角细边 | 这一排已经是文字了，再放一个 emoji 就是异类 | 占宽 ≈ 76px；而且长得像 pin-chip，容易被当成可点的会话 |
| **B** | **线描铃铛**（SVG，`currentColor`）+ 数字，无底色、无黄色 | 换个图标就够，继续用「铃铛」这个全世界都认识的隐喻 | 仍是一枚图标，与这一排的文字不齐 |
| **C** | **方章数字**：1px 细边方块里一个 `2`，没有图标 | 你要的是数字，不是铃铛；它像计数器，不像提醒 | 第一眼没人知道那是什么（只有 hover title） |
| **D** | **不新增控件**：数字画在**当前会话那颗胶囊的尾巴**上 | 你在等的是会话，不是「通知」 | ★ 行空着时无处可挂；数字看起来像这个小会话自己的未读 |
| **E** | **一个点 + 小字**：6px 圆点 +「2 件在等」，颜色只到 `--faint` | 这条指示器不该抢任何注意力 | 太安静 —— 而这正是当初要做它的理由（盯中间时看不见） |

## 0 件时怎么收场（原型里也拍出来了）

| A | B | C | D | E |
| --- | --- | --- | --- | --- |
| 整颗消失 | 留一枚灰铃铛，无数字 | 整颗消失 | 尾巴消失（不留空圈） | 留一个灰点，无数字 |

「有事才出现」还是「一直在、只是变灰」是个真实的取舍：前者干净，但位置会跳；后者稳定，但这排本来就挤。

## 结论

还没定 —— 等你挑（或者组合：比如「B 的图标 + C 的方块数字」、「D 的位置 + B 的铃铛」）。落地时按 `web/src` 的规矩重写：`tr()` 三语、`#app` 里不许裸 `vh`/`vw`、图标走 `currentColor` 而不是 emoji。
