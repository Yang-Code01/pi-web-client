# 提醒中心 · UI 样张（一次性原型）

**这份原型要回答的问题：** 顶上那颗角标点开之后，那一栏到底长什么样？五个变体结构上互相不认同（不是换配色），翻一遍就知道哪个更像你每天会点开的东西。

**它不回答：** 状态怎么流转、角标怎么算。那是旁边 `../reminders-logic/` 的事。

形状的大前提已经定了（`docs/DECISIONS.md` 的 **D389**）：别的会话在等你时，右上角弹一条自己消失的吐司 + 一个常驻角标 + 点角标开一栏清单；清单只负责跳转，不复制审批 UI。

**角标的位置按你的意见改过**：第一版钉在顶栏（跟文件 / 终端 / 内网通那一排挤），现在是 **★ 行（会话层那一行）的最右端**，挨着 `＋`。理由是它讲的事就是会话。

## 怎么跑

双击 `index.html` 就行（没有构建、没有后端、数据全是死数据）。或者：

```bash
open proto/reminders-ui/index.html          # macOS
# 直接开某一片样张：
open 'proto/reminders-ui/index.html?variant=C&toast=0'
```

- 底部浮条上 **‹ ›** 换变体，`←` `→` 也行；当前变体写进 URL 的 `?variant=`，可以发给别人。
- `弹一条吐司` 看重播；`窄版` 收掉左栏；`深色` 换 Mac 深色那套 token。
- `?toast=0` 关掉打开时那条吐司（截图用，免得两张图差在一个计时器上）。

## 五个变体各赌什么

| | 形态 | 赌的是 | 代价 |
| --- | --- | --- | --- |
| **A** | ★ 行右端角标 → 下拉清单（340px，每条两行） | 清单只负责「让你知道 + 跳过去」 | 跨会话一多，清单就是一个长流水 |
| **B** | 同一个角标位置 → 极密单行列表（256px，正文悬停才出） | 你一屏能扫完，认得快 | `rm -rf dist/` 这种得先悬停才敢点 |
| **C** | 角标仍在 ★ 行右端 → 右侧固定窄抽屉（320px） | 你愿意腾出 320px，让它停在那一格一格处理 | 窄屏要么全宽盖住正文，要么干脆不出 |
| **D** | 角标在同一位置 → 点开不是小下拉，而是贴着输入框升起的整条两栏面板（全宽） | 条目多时最省滚动，一屏看完 | 盖住正文底部，读长文时最碍事 |
| **E** | 同一个角标位置 → 按**会话**分组（一张卡装一个会话的全部等待） | 你关心的是「哪个会话在等我」，不是「哪一条」 | 跨会话的「最近的先看」读不出来 |

截图：`shot-A.png` … `shot-E.png`，另加 `shot-toast.png`（吐司单张）、`shot-narrow.png`（620px 宽）。
重拍：`node proto/reminders-ui/shots.mjs`（只拍某几个：`node proto/reminders-ui/shots.mjs A E`）。它顺手断言「清单开了、五条都在、角标是 2、没有 JS 报错」。

## 结论（2026-11-23）

**赢的是 A 的形状 + E 的一套读法：**

- 角标：**★ 行（会话层那一行）的最右端**，挨着 `＋`；不占顶栏、不用抽屉、不要底部状态带。
- 面板：**贴在角标下方的小下拉**（340px，两行一条）—— C 的抽屉与 D 的宽面板都不做。
- 清单结构：**两套，一个切换**。默认「按事件」的流水（最新在上、按天分组，A 那个样子），表头切一下变成「按会话」分组（E 那个样子，一张卡一个会话）。两种读法回答的是两个问题 ——「谁先等的」「哪个会话在等我」—— 都值得留，但不要分成两个入口。

**代价（写进实现里要知道）：** 切换键是纯前端状态，别让它进桥；`localStorage` 记最后一次选的读法就够了。分组视图要求同一个会话的条目能合到一起，所以 `Reminder` 里的 `sessionId` 是必填的（非阻塞条目没有会话时要落到「其它」一组）。

其余三片（B / C / D）留着当反例：B 的密度证明「正文悬停才出」在 `rm -rf dist/` 这种条目上不成立；C 证明抽屉要吃掉 320px 正文；D 证明全宽面板在长文阅读时最碍事。

**这是原型**：配色/间距/文案都是随手写的，赢的那片落地时要按 `web/src` 的规矩重写（`tr()` 三语、`#app` 里不许裸 `vh`/`vw`、窄版用 `@container`），不是把这里的 CSS 抄过去。`#app` 里那个「网格行数必须对得上子元素」的坑在原型里也踩了一次（多插一行会话行，主体掉进 auto 行），落地时同类改动要顺手看一眼 `grid-template-rows`。
