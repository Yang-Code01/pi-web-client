按钮可见性 · 三个样张

要回答的问题只有一个：「外观与语言」里那 11 颗的开关，长什么样最好用？ 三张都是真的 HTML，点开就是真外壳 + 真 sheet，底下那条胶囊是原型专用的换版条（← → 也能换）。

  • 11 颗固定
  • Aa 不能关
  • 恢复默认不碰它们
  • 每组一个「全部显示」
  • 关掉＝真拿掉，空间还回去
  • 首选存桥端（换设备同一份）
A

双列清单

最省地方：一组两列、34px 一行，11 颗只占六行。眼睛顺着勾走，跟设置里其它清单一个语言。

 B

实时预览

先画一遍你的顶栏和输入框：点哪颗，那颗就从画里消失。还能把预览切到手机宽，看见「自动收起」到底是怎么收的。

 C

三态分段

把「显示 / 自动 / 隐藏」摊在明面上：自动＝照默认走（手机上文件夹自己会收）。多一列按钮，换掉一整类「我明明勾了它怎么没了」的困惑。

三张都是 .scratch/chrome-visibility/prototype/ 里的一次性代码，看完就扔；选中的那版会按 spec 重写进 web/src/app.ts。换版也可以直接改地址：sheet.html?variant=A|B|C。
